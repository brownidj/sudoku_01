# ZuDoKu Free Version vs Full Version

## Purpose

ZuDoKu is a senior-friendly Sudoku-style app that replaces numbers with themed images. The free version should be genuinely playable and enjoyable, while the full version should unlock more variety, challenge, feedback, and replay value.

The guiding principle is:

**Free should prove the concept. Full should deepen the experience.**

---

## Overall Product Model

| Version | Role |
|---|---|
| **Free Version** | A complete, friendly, playable introduction to ZuDoKu. It should feel generous rather than restricted. |
| **Full Version** | The richer long-term version, with more themes, more difficulty levels, metrics, and enhanced replay features. |

The recommended business model is:

**One free app download with a one-time premium unlock.**

This is preferable to maintaining separate Lite and Pro apps.

---

## Free Version

The free version should include the core experience and enough content to make the app attractive to seniors.

| Feature Area | Free Version Recommendation |
|---|---|
| **Core gameplay** | Included. Users should be able to complete full puzzles. |
| **Image-based Sudoku mechanic** | Included. This is the app’s main differentiator and should be visible immediately. |
| **Difficulty levels** | Include **Easy** plus one additional accessible level. |
| **Themes** | Include a small number of starter themes. Enough to show variety, but not all themes. |
| **Celebrations** | Include basic end-of-game congratulations and celebration. |
| **Sounds** | Include basic sound effects or basic themed sounds. |
| **Metrics** | Limited or locked. Avoid giving away the richer progress-tracking features. |
| **Premium prompts** | Locked features should be visible, clearly marked, and explained politely. |

### Recommended Free Content

| Item | Include in Free Version? | Notes |
|---|---:|---|
| Easy puzzles | Yes | Essential for senior-friendly onboarding. |
| One additional level | Yes | Gives the free version some replay value. |
| Hard / Very Hard levels | No | Reserve for full version. |
| Starter image themes | Yes | Include enough to demonstrate the app’s personality. |
| All image themes | No | Strong premium incentive. |
| Basic celebration | Yes | Helps make the app encouraging and replayable. |
| Basic sounds | Yes | Adds fun and accessibility. |
| Time to complete | Maybe limited | Could be shown simply, but richer metrics should be premium. |
| Personal best | No | Better reserved for the full version. |
| Extra statistics | No | Premium feature. |

---

## Full Version

The full version should feel like a meaningful expansion, not merely the removal of annoyances.

| Feature Area | Full Version Recommendation |
|---|---|
| **Difficulty levels** | Unlock all levels, including harder levels. |
| **Themes** | Unlock all current and future included image themes. |
| **Metrics** | Include time to complete, personal best, and other progress feedback. |
| **Celebrations** | Add richer, more varied, or more satisfying celebrations. |
| **Sounds** | Add more themed sounds and optional sound sets. |
| **Replay value** | Use variety, challenge, and progress tracking to encourage repeated play. |

### Recommended Full Version Content

| Item | Include in Full Version? | Notes |
|---|---:|---|
| Easy puzzles | Yes | Still available. |
| Medium puzzles | Yes | Could be the second free level or part of full access. |
| Hard puzzles | Yes | Premium value. |
| Very Hard puzzles | Yes | Premium value for users who want more challenge. |
| All starter themes | Yes | Included. |
| All premium themes | Yes | Major premium feature. |
| Enhanced celebrations | Yes | Supports the fun/senior-friendly positioning. |
| Extra/themed sounds | Yes | Good for theme packs and replay value. |
| Time to complete | Yes | Useful performance metric. |
| Personal best | Yes | Encourages replay. |
| Additional metrics | Yes | Add gradually if useful and not cluttered. |
| Restore purchases | Yes | Essential for in-app purchase reliability. |

## Difficulty Level Structure

A sensible structure would be:

| Level | Free or Full? | Purpose |
|---|---|---|
| **Easy** | Free | Friendly entry point. |
| **Medium** | Free or Full | Good second free level if you want the free version to feel generous. |
| **Hard** | Full | Adds premium challenge. |
| **Very Hard** | Full | Adds long-term value for more capable users. |

A good free split would be:

**Free: Easy + Medium**  
**Full: Easy + Medium + Hard + Very Hard**

If Medium is too generous, use:

**Free: Easy + Easy Plus**  
**Full: Medium + Hard + Very Hard**

## Themes

Themes are one of the strongest premium incentives because they are highly visible and directly tied to the app’s distinctive image-based design.

| Theme Type | Free Version | Full Version |
|---|---:|---:|
| Basic starter theme | Yes | Yes |
| One or two attractive extra themes | Yes | Yes |
| Animals | Maybe starter or premium | Yes |
| Ocean creatures | Premium | Yes |
| Transport | Premium | Yes |
| Opera singers | Premium | Yes |
| Planet / space set | Premium | Yes |
| Future theme packs | Optional | Optional add-ons or included in premium |

The free version should include enough themes to show that the app is visually different from ordinary Sudoku. The full version should unlock the feeling of variety.

---

## Metrics

Metrics are better suited to the full version because they support long-term engagement.

| Metric | Free Version | Full Version |
|---|---:|---:|
| Completion shown | Yes | Yes |
| Time to complete | Limited or locked | Yes |
| Personal best | Locked | Yes |
| Best time by difficulty | Locked | Yes |
| Best time by theme | Locked | Yes |
| Completion history | Locked | Optional |
| Streaks | Optional | Optional |

For seniors, avoid making metrics too competitive or stressful. Use wording such as:

**Your best time**  
**Your latest time**  
**You improved!**  
**Well done — puzzle completed**

---

## Tone of Locked Features

Locked features should be friendly and encouraging, not punitive.

Good wording examples:

- **Available in the full version**
- **Unlock more themes and harder puzzles**
- **Full version includes personal bests and extra themes**
- **Upgrade once to unlock all current premium features**

Avoid wording that makes the free version feel inadequate, such as:

- “You cannot use this”
- “Premium users only”
- “Access denied”

## Suggested Premium Positioning

The full version can be positioned as:

**A one-time unlock for more themes, more challenge, and personal progress tracking.**

Suggested price range discussed:

| Price | Positioning |
|---:|---|
| **A$7.99** | Lower-friction, accessible price. |
| **A$9.99** | Recommended default. |
| **A$12.99** | Higher-value positioning, but possibly more resistance. |

Recommended starting point:

**A$9.99 one-time unlock**

## Testing the Full Version

For Android internal testing, testers should ideally test the real unlock path.

Recommended setup:

1. Add testers to the **Internal testing** track so they can install the app.
2. Add the same accounts to **License testing** so they can make test purchases without being charged.
3. Ask testers to test:
   - buying the premium unlock,
   - restarting the app,
   - uninstalling and reinstalling,
   - restoring premium access,
   - accessing locked themes and levels.

Avoid relying only on a special “always premium” test build, because that does not test the actual purchase and restore logic.

---

## Copyright and Audio Caution

Free upgrades are still public app distribution. Free to the user does not mean rights-free.

For music or sound themes, avoid bundling copyrighted songs or recordings unless properly licensed. Safer options include:

- royalty-free audio,
- public-domain recordings where the recording itself is also public domain,
- original commissioned clips,
- sound-alike mood clips that do not copy recognisable melodies, lyrics, or arrangements.

This is especially important for well-known artists or songs.

## Recommended Final Split

The strongest current recommendation is:

### Free Version

- Complete playable puzzles.
- Image-based Sudoku mechanic.
- Easy level.
- One additional accessible level.
- A small number of starter themes.
- Basic celebration.
- Basic sounds.
- Visible but locked premium features.

### Full Version

- All difficulty levels.
- All standard themes.
- More challenging puzzles.
- Time to complete.
- Personal best.
- Extra metrics if useful.
- Enhanced celebrations.
- Extra themed sounds.
- Restore purchase support.

---

## Summary

The free version should be good enough that seniors enjoy playing it and understand why ZuDoKu is different. The full version should then offer more variety, more challenge, more feedback, and more long-term replay value.

The best product message is:

**Enjoy ZuDoKu for free. Upgrade once to unlock more themes, harder puzzles, and personal bests.**
